PREPFIX Timetable Toolkit V1

This is the school's own copy of PREPFIX Timetable Toolkit V1. Make the timetable in FET or aSc Timetables as usual; PREPFIX gives it a clean look, prints it and sends it to teachers' phones. It never changes the timetable.

First time only

1Install Python from python.org/downloads — on the first screen tick Add python.exe to PATH, then Install Now.
2Copy this whole folder to a permanent place (e.g. Documents) and double-click Start PREPFIX.bat. Nothing else to set up.

Every time a timetable is ready

1Open Start PREPFIX.bat → Import & Run.
2Add the timetable: the folder FET made, or the PDFs printed from aSc Timetables (the class and the teacher timetables, both together).
3Add notes if you wish → Preview → print. Press Publish to send it to teachers' phones.

Teachers who may open the timetables

Only teachers this school registers can open its timetables on a phone — nobody from another school.
1Open PREPFIX → click the school → 👥 Teachers & phones.
2+ Add teacher (name and phone number) or 📋 Paste a list, then 💾 Save the list.
3Share the app link. Each teacher types the registered number and makes their own 4-number PIN, once. Install appears after signing in. One number = one phone.
4Wrong person signed in, or a teacher forgot the PIN? Click the teacher → 🔓 Remove sign-in; the teacher then signs in again with a new PIN. ↻ Who has the app? shows who is signed in.

New laptop

Open Setup → Back up everything: Save now and keep the saved folder on a flash disk. On the new laptop, copy this folder, start PREPFIX → Setup → Import my saved folder. Everything comes back.
